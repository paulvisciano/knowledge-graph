# Vision

Knowledge Graph is the private layer of Sci-Fi Labs.

It is not a chatbot. It is the file browser for a computer you own — an intelligent map of conversations, photos, documents, and journal entries that you talk to instead of hunting folders.

## Where it sits

1. **OS** — [Omarchy](https://omarchy.org/). Arch, Hyprland, agents as first-class tools. The graph is meant to run natively on that desktop, not only as a localhost web app.
2. **Air gap** — Sensitive files live on an external drive. Plug it in: the graph loads. Unplug it: the AI has no access. Photos, conversations, financials, medical records stay physical.
3. **Public apps** — [Where is Paul?](https://github.com/paulvisciano/where-is-paul), [Musical Cubes](https://github.com/paulvisciano/musical-cubes), [Neuro Graph](https://github.com/paulvisciano/neuro-graph) are the public faces. They publish what you choose. The graph keeps what you don't.

## Lineage

JARVIS (git as memory) → Neuro Graph (public network) → Knowledge Graph (private engine on-device).

Same thesis the whole way: memory as a place you walk, not a window you rent.

## What winning looks like

You install Omarchy. You plug in the drive. You speak to your files. Then you open a spatial web app on the same machine — a globe, a cube, a graph — and the private layer and the public layer share a timeline without the private layer ever leaving the box.
